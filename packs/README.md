# Discipline content packs

These v1 JSON files provide editable starting points for rank systems, programs,
and class tags. They contain original data assembled from public grading facts;
they include no technique syllabus, promotion requirements, or copied curriculum.

Ranks and sub-ranks appear in progression order. IDs are stable within each pack.
A rank's base grade means no stripe or degree; its sub-ranks represent subsequent
stripes or degrees. Programs reference rank systems in the same pack.

Each `color` is a representative display swatch, not an official color
specification. Names retain the full description of multicolor belts because the
v1 format stores one color per rank.

- **BJJ:** adult and youth belt order follows the
  [IBJJF graduation system](https://ibjjf.com/graduation-system).
  White through brown adult belts have four optional stripes; black has six
  degrees before the separate coral and red belts. Youth stripe schemes vary,
  so the youth system supplies belt ranks without imposing a stripe scheme.
  The age labels describe the systems, not eligibility for every belt.
- **Judo:** the kyu progression follows
  [Judo Canada's grading page](https://judocanada.org/grading/): white (6th kyu),
  yellow, orange, green, blue, and brown (1st kyu). Each "+" intermediate belt
  (white-yellow through blue-brown) is a sub-rank of the kyu below it. Dan belt
  colors follow the
  [IJF's belt history](https://www.ijf.org/news/show/the-belt-myth-and-reality-of-an-essential-symbol).
  Other federations use different kyu colors, so gyms can rename ranks and
  change their colors after applying the pack.
- **Karate:** a generic starting point using a color order common in North
  American schools: white (9th kyu), yellow, orange, green, blue, purple, then
  brown for 3rd through 1st kyu, followed by ten black-belt dan grades. No single
  federation defines this sequence; karate associations and styles each set their
  own, so gyms can rename ranks and change their colors after applying the pack.
- **Muay Thai:** this starting point has no rank system.
  [Rajadamnern Stadium describes traditional and modern grading approaches](https://rajadamnern.com/blog/ranking-system-in-muay-thai/).
  Gyms using an association's Khan or armband scheme can configure their own grades.
- **Functional fitness:** this starting point has no rank system. Programs and
  class tags describe training formats rather than athlete grades.

The program names and class tags are suggestions for organizing classes; they
are not federation endorsements or prescribed training plans.
